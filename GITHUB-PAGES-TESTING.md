# GitHub Pages Testing

This repository is prepared for temporary GitHub Pages testing.

1. In GitHub, open **Settings > Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select branch **main** and folder **/(root)**, then Save.
4. The test URL should be: `https://HintonStarPlayer85.github.io/Designing-Virtuosity-Web/`

The HTML pages in this staging copy include `noindex, nofollow` so search engines should not treat the temporary test deployment as the production Designing Virtuosity site. Remove that robots meta tag before the final production migration.

The repository is currently private. If GitHub Pages is unavailable for this private repository under the account's GitHub plan, change the repository visibility to public for the temporary staging period.
